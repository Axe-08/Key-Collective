API Documentation & SDK Quickstart

Plug-in compatible with standard OpenAI SDKs across Python, TypeScript, and cURL.

Authentication & Base URL

Pass your personal Key Collective bearer token in standard Authorization headers. Requests are automatically verified and multiplexed across healthy keys.

Base URL: https://api.key-col.axe08.tech/v1
Header: Authorization: Bearer kc_proj_live_...

Supported Endpoints

POST /v1/chat/completions Streaming SSE supported
GET /v1/models Dynamic registry
Python (OpenAI SDK) v1.0+ compatible 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.key-col.axe08.tech/v1",
    api_key="kc_proj_live_..."
)

response = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[
        {"role": "user", "content": "Ping!"}
    ],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
